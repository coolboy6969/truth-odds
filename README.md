# TruthOdds — Система оценки вероятности событий по заявлениям известных людей

Платформа для сбора прогнозов инфлюенсеров и экспертов (из YouTube, социальных сетей и интервью), ведения их персонального рейтинга правдивости (**Brier Score & Calibration**) и байесовского расчета итоговой вероятности будущих событий с учетом авторитетности каждого спикера.

---

## 💡 Ключевая концепция и математика

### 1. Рейтинг правдивости эксперта (Calibration & Brier Score)
Оценка спикера рассчитывается строго по фактическим результатам его прошлых прогнозов:

$$BS = \frac{1}{N} \sum_{i=1}^N (f_i - o_i)^2$$

* $f_i \in [0, 1]$ — вероятность, которую прогнозировал спикер.
* $o_i \in \{0, 1\}$ — реальный исход события (1 — сбылось, 0 — не сбылось).
* **0.00** — идеальная пророческая точность.
* **0.25** — уровень случайного угадывания (монетка 50/50).
* **> 0.25** — отрицательная точность (систематический оверконфиденс или обратный индикатор).

### 2. Вес доверия со сглаживанием (Bayesian Shrinkage)
Чтобы предотвратить завышенный вес у людей с 1 случайным попаданием, используется сглаживание:
$$W_i = \frac{M \cdot W_0 + N \cdot \text{RawCredibility}}{M + N}$$
где $M = 3$ — априорное число наблюдений со средним весом $W_0 = 0.5$. По мере роста проверенных прогнозов ($N$) вес сходится к реальной точности эксперта.

### 3. Байесовский расчет вероятности события (Log-Odds Aggregation)
Когда несколько экспертов высказываются по одному событию, их мнения объединяются в логарифмических шансах:

$$L_{\text{posterior}} = L_{\text{base}} + \sum_{i=1}^K w_i \cdot \left( L_i - L_{\text{base}} \right)$$

$$P_{\text{итог}} = \frac{1}{1 + e^{-L_{\text{posterior}}}}$$

* Голос эксперта с высоким рейтингом (**85%**) сильно сдвигает вероятность.
* Заявления кликбейтного блогера с низким рейтингом (**15%**) практически игнорируются системой.

## 🚀 Быстрый старт

### 1. Активация окружения и зависимости
Проект уже развернут в виртуальном окружении `.venv`:
```powershell
.\.venv\Scripts\activate
```

### 2. Запуск сервера
```powershell
python -m uvicorn app.main:app --reload --port 8000
```

После запуска перейдите в браузере:
* **Веб-дашборд:** [http://127.0.0.1:8000](http://127.0.0.1:8000)
* **Интерактивная документация Swagger API:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 🖥 Возможности веб-интерфейса

1. **Оценка событий (Events Tab):**
   * Визуализация рассчитанной вероятности (0–100%) с цветовой градацией.
   * Список цитат спикеров с отображением их персонального веса доверия.
   * Кнопка **"Разрешить событие (Oracle)"**: позволяет завершить событие как TRUE или FALSE и в реальном времени наблюдать, как пересчитываются рейтинги авторов!
2. **Лидерборд экспертов (Leaderboard):**
   * Таблица спикеров с Brier Score, Hit Rate (%) и доменной разбивкой (Crypto, Tech, Macro).
   * Присвоение статусов (*Superforecaster*, *Надежный*, *Обратный индикатор*).
3. **Анализ YouTube и цитат (Ingestion Tab):**
   * Вставка ссылки на видео YouTube (автоматическое получение транскрипта) или текста высказывания.
   * Автоматическое извлечение гипотезы события, горизонта времени и уверенности спикера.

## ⚙️ Настройка LLM (опционально)

По умолчанию в системе работает умный эвристический анализатор уверенности и доменов, не требующий внешних ключей. Для подключения нейросетей создайте `.env`:
```env
# Google Gemini (рекомендуется)
GEMINI_API_KEY=your_gemini_api_key

# Или OpenAI
OPENAI_API_KEY=your_openai_api_key
```
